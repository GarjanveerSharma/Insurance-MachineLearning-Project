# Insurance-MachineLearning-Project

# 🏥 Insurance Machine Learning Project

A complete **Machine Learning data preprocessing pipeline** that transforms raw insurance data into a clean, model-ready dataset. This project demonstrates the essential steps performed before training any ML model, including data cleaning, feature engineering, encoding, and scaling.

## 📌 Project Overview

The dataset was collected from **Kaggle** and contains information related to insurance charges such as age, BMI, smoking status, region, and more.

The primary goal of this project is to convert the raw dataset into a format suitable for machine learning algorithms by applying industry-standard preprocessing techniques.

---

## 🚀 Features

* 📥 Load raw dataset from Kaggle
* 🔍 Explore and inspect data
* 🧹 Handle missing values (if present)
* 📊 Perform Exploratory Data Analysis (EDA)
* 🔤 Encode categorical features
* 📏 Scale numerical features
* 🏗️ Build a reusable preprocessing pipeline
* 💾 Save the processed dataset for future model training
